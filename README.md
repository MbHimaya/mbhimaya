# MB Himaya ওয়েবসাইট

সিম্পল ও ক্লিন ডিজাইনের ব্যক্তি পরিচিতি পোর্টাল।

## ফাইলগুলো
- `index.html` → মূল পেজ
- `style.css` → ডিজাইন
- `script.js` → সার্চ ও মডাল ফাংশন
- `data.json` → সব তথ্য এখানে (এটা এডিট করে আপডেট করবেন)

## কীভাবে নতুন ব্যক্তি যোগ করবেন / আপডেট করবেন

`data.json` ফাইল খুলে এডিট করুন।

উদাহরণ:

```json
{
  "id": 5,
  "name": "নতুন ব্যক্তির নাম",
  "mainImage": "ছবির-লিংক.jpg",
  "images": [
    "ছবির-লিংক-১.jpg",
    "ছবির-লিংক-২.jpg"
  ],
  "description": "বিস্তারিত বিবরণ এখানে লিখুন।"
}
```

- `id` → প্রতিবার নতুন সংখ্যা দিন (১, ২, ৩...)
- `mainImage` → মূল ছবির লিংক
- `images` → অতিরিক্ত ছবির লিংকগুলো (অ্যারে)
- `description` → বিস্তারিত তথ্য

ছবি আপলোড করতে চাইলে:
1. ছবিগুলো imgur.com বা cloudinary.com এ আপলোড করুন
2. সরাসরি লিংক কপি করে `data.json` এ বসান

## ফুটারের লেখা পরিবর্তন
`index.html` ফাইলের নিচের `<footer>` অংশ এডিট করুন।

## হোস্টিং (ফ্রি)

### Netlify (সবচেয়ে সহজ)
1. https://netlify.com এ গিয়ে সাইন আপ করুন
2. "Add new site" → "Deploy manually"
3. এই ফোল্ডারের সব ফাইল ড্র্যাগ-ড্রপ করুন
4. সাইট লাইভ হয়ে যাবে (যেমন: random-name.netlify.app)
5. Site settings → Domain management → এডিট করে `mbhimaya` নাম দিতে পারেন

### Vercel
1. https://vercel.com এ সাইন আপ
2. New Project → ফোল্ডার আপলোড
3. Deploy

## .com ডোমেইন কানেক্ট করতে চাইলে

1. Namecheap / Cloudflare / GoDaddy থেকে `mbhimaya.com` কিনুন
2. Netlify বা Vercel ড্যাশবোর্ডে গিয়ে Custom Domain যোগ করুন
3. DNS সেটিংসে তারা যে Nameserver বা A/CNAME রেকর্ড বলে দিবে সেগুলো ডোমেইন প্রোভাইডারে বসিয়ে দিন
4. ৫ মিনিট থেকে কয়েক ঘণ্টার মধ্যে ডোমেইন কাজ করবে

## লোকাল টেস্ট
ফোল্ডারটি ডাবল ক্লিক করে `index.html` খুললেই চলবে (কিছু ব্রাউজারে fetch কাজ নাও করতে পারে, তাই Live Server ব্যবহার করুন)।
